# XGBoost-Cox Survival Analysis for Preeclampsia

This repository contains the R Markdown source code and project configuration files for the paper on preeclampsia survival modeling using the **XGBoost-Cox** algorithm.

## 📖 Publication
* **Journal**: Indonesian Journal of Statistics and Its Applications (IJSA)
* **Article Link**: [IJSA IPB - Article 1289](https://journal-stats.ipb.ac.id/index.php/ijsa/article/view/1289)

## 📁 Repository Structure
* `XGB-Cox.Rmd`: Primary R Markdown script containing data analysis, model training, and evaluation.
* `XGBoost_Survival.Rproj`: RStudio project file for environment setup.
* `renv.lock`: Package dependency lockfile ensuring computational reproducibility.
* `best_params.rds`: Saved optimal hyperparameters for the XGBoost model.

---
> ⚠️ **Data Privacy Notice**: The raw dataset (`Final.xlsx`) is excluded from this repository to protect patient confidentiality and adhere to medical data compliance standards.
